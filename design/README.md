# Rebrand direction (Oct 2026)

Mockup canvas: https://claude.ai/artifact/HfAdSvNtAFwvr59qsN8FvR
The `.dc.html` files in `swiss-mockup/` are the canvas boards (they render on the canvas, not standalone). `Swiss.dc.html` is the chosen design.

## Look: Swiss
- Strict 12-column grid, one typeface (Inter Tight), tabular numerals.
- Huge numerals for the key number (Hunt Score), thin rules instead of cards.
- Sections in story order, each with a small muted one-word label (Score, Factors, Form, History, Matchup) over a bold title; no numbers.
- Score build-up table (baseline, minutes, form, matchup, position matchup, pace, book line, uncertainty), diverging over/under bars from a center line, paired percentile bars on a fixed 0-100 scale.
- Player name: first name ~70% of the last name; jersey number next to the last name in a light muted weight.
- Teal / coral stay the only loud colors. Wordmark is a placeholder for the rebrand.
